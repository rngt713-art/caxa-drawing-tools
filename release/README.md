# CAXA 图纸上传助手 v1.0.0

本 Release 只提供编译后的上传端 EXE 和本说明。源码请从 GitHub 仓库 clone：

```text
https://github.com/rngt713-art/caxa-drawing-tools.git
```

## 运行环境

- Windows
- 已安装 CAXA 协同管理 2011 客户端
- 当前账号具备 CAXA 图纸新建、修改和关系维护权限
- 能访问现场 CAXA 服务器

## 使用

1. 双击 `图纸上传助手-v1.0.0.exe`。
2. 填写当前使用人的 CAXA 用户名和密码；密码允许为空。
3. 打开识别端导出的上传包，或直接拖入按 `图号 名称.pdf` 命名的 PDF。
4. 检查文件名、图纸类型、成品代码和层级关系。
5. 点击“检查上传包/设计树预检”。
6. 预检通过后点击“上传图纸”。
7. 需要发起审核打印时，填写审核人并勾选“上传成功后发起审核打印流程”，
   或上传完成后使用“发起流程”。

程序始终上传用户选中的原始内容副本，不会改名或覆盖源 PDF。同一批内容再次
提交不会重复上传已确认成功的图纸。

## 02 半成品层级

- `02.A36.02.AR02` 从最近点号上级 `02.A36.02` 开始向上寻找已有 Part。
- 只创建缺失的末级 Part，并挂到最近上级。
- 同一图号只能有一个原件。
- 多个产品/上级挂接合法，但只允许一个 `reference=False` 归属，其他必须是借用。

## 待核实

超时、helper 退出或写入后回读失败时，操作会标记为“待核实”，程序不会自动重放。
请在“核实待定结果”窗口中回读 CAXA 证据，或人工确认未写入后再重试。

## 日志与配置

- 配置：程序目录 `config.json`
- 任务日志：`%LOCALAPPDATA%\caxa_upload_journal\journal.sqlite3`
- 密码使用当前 Windows 用户的 DPAPI 加密，不能直接复制到其他电脑解密。
