# CAXA 图纸工具真机测试与验证清单（最终锁定版）

本清单已同步全部锁定的业务与交互规则（**1a / 2b + 一键改名 / 3a / 4a + 局域网精简**），对应的代码改动已同步写入修订源码包。只需在安装有 **CAXA 协同管理 2011（EAP 2011r3）** 的客户端真机上按本表完成验证即可。

## 1. 已最终锁定的规则与实现对照

| 编号 | 规则项 | 最终实现逻辑 |
| :--- | :--- | :--- |
| **1a** | **通用件归属、整机借用与系列产品** | 1. **自动层级**：普通零件在 Product `01 通用件` 下按图号最近前缀建立唯一的 `reference=False` 归属路径；`01.x.*` 挂到同一 `01.x.*` 系列父级时默认归属，`x` 不同才默认借用。<br/>2. **多借用**：03 整机及其他跨系列上级为 `reference=True`；同一组件可借用到多个 03 整机。<br/>3. **03系列产品**：每台 03 整机在树中各自建立 Product 分组并作为产品子级；双击 03 行填写独立产品名称，以整机图号作为产品代号创建或复用。<br/>4. **人工勘误**：在层级树中双击关系行或点击“切换 归属子件 / 借用”即可切换并锁定为 `[人工]`。 |
| **2b+** | **单字母工艺与数字图纸命名 + 一键改名** | 1. **识别端导出**：单字母工艺文档（`Z03`/`M03`/`T03`/`J03`/`P03`）直接导出为 `图号.pdf`（自动裁去中文名）；数字开头图纸（`01`/`02`/`03`/`04`）导出为 `图号 名称.pdf`。<br/>2. **上传端校验与一键改名**：拖入带中文名的单字母工艺文档（如 `Z03.OV.04-05030 总装图.pdf`）或多字母错误前缀（如 `ZJ03.*`）时标红提示；双击修正图号后点击**“一键规范文件名”**按钮，自动将本地文件重命名为标准格式（单字母裁去中文名、数字图号补齐单空格名称）并解除标红。 |
| **3a** | **已发布图纸拦截与追加版次校验** | 当重复策略为 `append_iteration` 时，上传前检查目标零件下同名/同图号图纸状态：若处于**“发布”**状态，直接将该行标记为 **`失败：图纸已发布，无法追加版次`**，继续上传本批其余图纸，并在结束后阻止自动发起“审核打印”流程；同时取消静默回退为 `reuse` 的旧逻辑，版次未增加时明确报错。 |
| **4a** | **窗口内轻量重试与局域网精简** | 1. **轻量重试**：不关闭上传窗口再次点击“上传图纸”时，自动跳过状态已为 `已上传` 的图纸和已完成的借用/归属链接，仅重试失败/待上传项；全部成功后发起流程时仍自动汇总本批全部已上传图纸的 `drawing_id`。<br/>2. **环境精简**：已删除 `server_main.py` 及局域网服务端脚本；`caxa_helper.cs` 已增加 C/D/E 盘 CAXA 默认安装目录探测，并修复 `CmdStartWorkflow` 吞异常及 `bridge.py` 重登缓冲错位问题。 |

## 2. 真机测试前准备

1. **重新编译 `caxa_helper.exe`（在 Windows 真机 PowerShell 中执行一次）**：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\caxa\caxa_helper\build_helper.ps1
   ```
2. **清空自动确认日志**：
   ```powershell
   Remove-Item "$env:TEMP\caxa_autoconfirmer.log" -ErrorAction SilentlyContinue
   ```

## 3. 分项真机测试用例

### 测试项 T1：一键规范文件名与单字母工艺文档验证（对应规则 2b+）

| 步骤 | 操作内容 | 预期结果 | 实测结果（通过/异常说明） |
| :--- | :--- | :--- | :--- |
| **T1-1** | 准备 3 个本地测试 PDF 拖入上传助手：<br/>1) `Z03.OV.04-05030 总装图.pdf`（带了中文名）<br/>2) `ZJ03.OV.04-05030 工艺.pdf`（错误多字母前缀）<br/>3) `01.59.OV.03  焊接管路包.pdf`（中间两个空格） | 3 行均标红显示“文件名不符合”且默认不勾选上传。 | |
| **T1-2** | 直接点击顶部**“一键规范文件名”**按钮。 | 第 1 个文件自动在本地被重命名为 `Z03.OV.04-05030.pdf`（裁去中文名），第 3 个文件自动重命名为 `01.59.OV.03 焊接管路包.pdf`，两行自动恢复正常并勾选上传；弹窗提示第 2 个文件 `ZJ03.*` 需先双击修正图号。 | |
| **T1-3** | 双击第 2 行，将图号从 `ZJ03.OV.04-05030` 改为 `J03.OV.04-05030` 保存，再点一次**“一键规范文件名”**。 | 本地文件自动重命名为 `J03.OV.04-05030.pdf`（无中文名），标红消失并勾选上传。 | |

### 测试项 T2：次级条目“树预检自动区分 + 人工双击切换”验证（对应规则 1a）

| 步骤 | 操作内容 | 预期结果 | 实测结果（通过/异常说明） |
| :--- | :--- | :--- | :--- |
| **T2-1** | 在主表拖入父图 `01.59.OV.03 焊接管路包.pdf`，再将树中不存在的新子件（如 `01.59.OV.03-99 测试件.pdf`）和树中已有的子件（如 `01.59.OV.03-03 二级缸进气管.pdf`）拖到 `01.59.OV.03` 行上。 | 两者直接缩进显示在 `01.59.OV.03` 下的同一棵层级树中。 | |
| **T2-2** | 填写 CAXA 账号密码，点击**“检查上传包/设计树预检”**按钮。 | 程序预检图号归属关系，并报告 03 整机所属系列产品是已存在还是待新建。 | |
| **T2-3** | 在层级树中双击任意子件行（或点“切换 归属子件 / 借用”）。 | 该行在 `归属子件` 与 `借用` 之间切换，并带有 `[人工]` 标记；再次点预检不会覆盖 `[人工]` 标记。 | |
| **T2-4** | 按住 `Ctrl`/`Shift` 多选两个子件，一起拖到新父级；再双击某父级行首 `+`/`-`。 | 新的归属父级会替换旧归属；借用父级可保留多个。双击 `+`/`-` 只展开或折叠，不弹出“修改上传信息”。 | |
| **T2-5** | 使用一台或多台 03 整机做小批测试，在每台 03 行分别填写产品名称，执行上传。另分别覆盖 `03.HW.*`、`03.HT.HGB.*` 和其他 `03.HT.*`。 | 每台 03 在树中有独立 Product 分组；上传时已有目录直接复用，缺失目录按路径创建；新产品分别挂到 `HW系列`、`HT合同特殊/HGB系列` 或 `HT合同特殊`。 | |
| **T2-6** | 上传新 04 组件并借用到两个 03 整机，随后在 CAXA 中检查。 | 04 组件在 Product `01 通用件` 下有唯一 `reference=False` 归属；两个 03 整机下各有 `reference=True` 借用链接。 | |

### 测试项 T3：“已发布”图纸拦截与“设计”图纸追加版次验证（对应规则 3a & 4a）

| 步骤 | 操作内容 | 预期结果 | 实测结果（通过/异常说明） |
| :--- | :--- | :--- | :--- |
| **T3-1** | 混选 1 张在 CAXA 中处于**“设计”**状态的图纸（如 `01.59.OV.03 焊接管路包.pdf`）和 1 张处于**“发布”**状态的图纸（如 `03.OV.04-05030 水冷无油增压机.pdf`），重复策略选 `append_iteration`，勾选“发起审核打印流程”，点击上传。 | 1. “设计”状态图纸成功追加新版次（`iterator_no` +1），状态变为 `已上传`；<br/>2. “发布”状态图纸被直接拦截，状态显示 **`失败：图纸已发布，无法追加版次`**；<br/>3. 因存在失败项，自动阻止发起审核打印流程。 | |
| **T3-2** | 不关闭窗口，在表格中取消勾选刚才报错的“已发布”图纸（或将策略改为 `reuse`），再次点击**“上传图纸”**（验证规则 4a 内存级重试）。 | 已是 `已上传` 状态的第 1 张图纸自动跳过不重传，剩余项处理完成后正常汇总全部 `drawing_id` 发起审核打印流程。 | |
